# Verification log

Every source the research phase used, what it was used for, and when it was read.
Append-only within a run; a re-run starts a new dated section rather than editing the
old one, so that a claim which was true in August and false in February leaves a
trace.

Why this file earns its place: a score is only as good as where it came from, and six
months later nobody remembers which pricing page said what. This is also what makes a
re-run cheap — the second pass re-checks the **V** rows and can usually leave the rest.

## Tiers

| Tag | Source type |

| **S** | Prep providers, training partners, resellers, blogs, forums, press |

## Contradictions

Where two sources disagree, both go here with the resolution and the reason. A
vendor page and a prep site disagreeing on eligibility or price is common enough to
expect, and the disagreement is often more informative than either claim alone.

## Dead ends

Pages that were gated, withdrawn, or that returned a status code that did not match
what was actually there. Recording them stops the next run spending its budget the
same way.
